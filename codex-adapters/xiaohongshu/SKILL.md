# 小红书读取

将 CC/Pi 的小红书读取经验适配到当前宿主浏览器。先用 mcp__cua_repl 提供的浏览器入口并读取其 API 文档；优先已有授权的登录会话。无需先安装 browser-act 或创建 stealth 浏览器；不执行原技能中的 shell eval、自动安装和浏览器删除流程。

## 三类请求

| 输入 | 工作与输出 |
|---|---|
| 搜索关键词 | 通过站内搜索和实际可见筛选控件选排序/类型，返回标题、作者、可见互动量、来源链接及采集时间 |
| 笔记 URL | 读取正文、标签、图文或视频信息；需要时展开评论，记录实际读取数量及是否尚有更多 |
| 用户主页 URL | 读取公开简介与当前可见笔记列表，按任务范围滚动，不将未加载记录当不存在 |

用真实页面卡片/链接进入详情。小红书链接常带 xsec_token 等上下文参数，保留观察到的完整 URL；不要根据 note_id 自造 token，也不要去掉查询参数再据错误页判定笔记已删除。页面重定向时回到正常站内导航核实一次；持续受限就准确报告。

旧脚本依赖 window.__INITIAL_STATE__ 和 Vue 状态，其结构、可见性与权限不保证当前仍适用。当前 CUA 只允许其文档明确支持的观察与 DOM 操作，不把旧状态提取代码直接迁入，不调用未观察的接口。评论和笔记列表按页面实际加载结果去重；不要输出身份凭据或无关个人字段。

如登录确实阻断目标，让用户在浏览器完成登录后继续。保留用户已有标签，结束只关闭自己创建的标签。读取请求不授权点赞、收藏、关注、私信、发评论或发布笔记。

结果区分作者陈述、评论观点与助手推断；互动量保留页面单位和采集时点。无来源链接或不可见字段就注明缺口，不编造热度和全量结论。
