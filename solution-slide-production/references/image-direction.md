# 调图翻译与生图指令

> 优先遵循当前客户模板与本套项目已获认可的成图；缺少新样图且需要华为工作汇报质感时，可按需读取内置预设[华为汇报风视觉预设](presets/huawei-report.md)。

## 把审美反馈翻译成能执行的修改

| 反馈 | 该改什么 |
| --- | --- |
| “高级、专业，后面沿用这个质感” | 直接和这张图对照标题基线、强调色用在哪里、浅灰分区有多轻、轮廓和图标有多细。允许模块有微弱层次；保持页面背景干净，消除大面积金属高光、光带和突兀饰线。 |
| “都是白，看不到侧重点”／“全黑灰太刻意” | 先决定缩略图里应当最先看到的业务对象。只突出该对象和真正重要的交接；其余区域用间距或轻微明度差分层。同套引入辅助色时给它明确定义。 |
| “字太多，但关键信息不能省” | 合并重复主语、共用约定、长副标题。例如把长串动宾句压缩为“对象查询 · 异常筛查 · 交叉取证”式并列短语。保留影响决策的口径、对象、输入输出、例外与责任。先压文案，再调排版。 |
| “傻大”“右侧单薄” | 前者连同标题、卡高、箭头和栏间距一起调整；后者先补图外真正需要的说明。侧栏与主图保持主次，具体宽度随信息量决定。 |
| “看不清全貌”“这个范围画错了” | 回读业务原文。用包围框、对齐或分层修正归属，再核对线的起点、终点和含义；图上哪怕一个外框圈错归属，都会改变读者对交付范围的理解。 |
| “这块图标拿掉”“把 1、2、3 和小图标加上” | 按本页最新指令处理，核对修改前后是同一组对象。编号能与总览里的能力编号对应时，可帮助跨页导航；纯装饰的编号或竖线按本页要求去掉。 |

## 可直接改用的两段指令

**新作一页**。将方括号替换为本轮材料。若已有参考图，同时附上。

> 为[受众]制作一张可直接投屏的 16∶9 中文方案内容页。本页要让读者看懂[一句具体判断]。以[参考图]为同套视觉依据，继承标题位置、灰阶、线重和图标尺度。本页主视觉为[真实对象与关系]，先读到[焦点]，再看到[支撑或结果]。[A]包含[B、C]；[D]与[A]同级；[X]调用[Y]获得[Z]。只使用本页事实对应的关系。上图文字采用[标题、标签、关键输出的精确文案]。画面保持干净底色、清晰中文和克制的强调色（采用华为汇报风预设时为纯白底与克制红色）。按业务关系选择构图，给连线标签和中文换行留空间。

**修改已有图**。尤其适合“上一版更好看，但这一版的内容对”。

> 图 A 是内容母版，沿用[已确认的文案、模块归属、交付范围、关键箭头及方向]。图 B 是风格母版，取它的[宽扁比例、标题层级、浅灰分区、局部重点]。这轮只改[用户指出的问题]。验收时重点看[两到三个可观察的变化]。

**实践要点（内容母版与风格母版分工）**：在多轮范围页/架构页迭代中，常出现“前一版的宽扁比例与视觉质感更佳，后一版才有需要保留的红标题、交付边界、旁注和双向关系”的情况。把两张参考图各自的职责写清，下一轮就能同时验业务含义和视觉效果；某个版本被选作参考，只代表对应属性有价值。
