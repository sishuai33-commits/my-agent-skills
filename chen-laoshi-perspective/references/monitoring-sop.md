# 监测 SOP（居民债务月报 + 季度营收统计）

> 来源：b5C 全文批蒸馏（模型H/模型I），2025-02 ~ 2026-07 共 9 篇月报 + 4 篇季报全文。
> 这是陈老师"数据跟踪者"身份的工程化实现——监测产品的完整生命周期管理。

## 一、居民债务月报 SOP（10 步）

**核心公式**：居民杠杆率 = 存量债务/GDP；**债务增速 < 名义GDP增速 = 降杠杆**
阈值随每季名义GDP更新：4.7% → 4.59% → 3.94% → 3.85% → 4.94%/5.89%

1. **理论锚**（每篇开头逐字重复，服务新粉）：美日港泡沫都在居民杠杆率下降中触底，首降→触底 3-5 年
2. **代理变量换算**：债务增速 < 名义GDP增速 → 降杠杆判定
3. **数据源诚实声明**：付费数据库拉城市级数据；无数据城市明列（广州/杭州/南京/成都…）——"杭州成都听说成交不错，但没数据公布我们无从判断"；苏州"数据太差全是负数，2月后停止更新"。**数据可得性本身就是信号**
4. **基数校正**：政策时点不同致同比失真→辅助看近几个月贷款绝对值增量；北京抬头=去年5月政策低基数；上海2026上半年同比6%=去年上半年新房高基数
5. **领先性换算链**：债务增速拐点 → 实际购买力拐点提前1-2个月（买房后过一两个月才贷款）→ 房价拐点。实例：上海债务增速5月拐点→购买力拐点3-4月→房价4月开始快速下行
6. **结构拆解**：买新房债务一定增加（开发商还贷计企业贷款）；买二手不一定（房东可能拿钱还债）
7. **预测验证闭环**：上海增速预判不超2021高点14.22%（实际13.93%拐点向下）→连续多期跟踪→"符合我们之前的预判"
8. **触发器定义**："如果未来出现无政策刺激下的居民杠杆率上升，那么大家就要注意，大概率到了投资买房时点"——反向信号即买点
9. **日落条款**（2025-10-18）："由于居民杠杆率全面拐点下行，未来若没有监测到数据异常，将不再公布各城市债务增速"——监测产品自带停止条件
10. **参数本地化修正**（2026-07-23）：东京香港杠杆率下行从债务负增长算起（其房价拐点时GDP≈0）；中国名义GDP 4%+，从低于4%算起。"如果你觉得居民收入达不到4%（沪深300平均薪酬年均2%增长），则触底时间指引可能会后延"——**刻舟求剑的锚也要按本国参数重调**

## 二、季度营收统计 SOP（9 步）

**核心方法**：700+ 恒定样本（沪深300剩280+ + 中证500剩450+，五年/六年都在指数名单，剔除退市如海通证券/鹏都农牧/广汇汽车）

1. **发布节奏**：财报披露截止日次日统计
2. **恒定样本法**：样本恒定保证跨期可比；退市股剔除
3. **独立性论证**：800家各自独立审计+汇总→"造假误差缩小到可接受范围"→与统计局GDP/CPI/PPI/税收/规上数据互相校验（"看是互相符合还是互相打架"）
4. **成本递归拆解**：营收=税收+利润+成本；成本=人工+采购；"一家公司的采购成本则是另一家公司的营收……细化到最后，所有采购成本也都将变为人工成本"——**一切成本终归是工资**（传导链思维的微观基础）
5. **核心传导判断**：营收跌+利润升=压成本=降薪裁员+供应商订单下滑→"企业至暗时刻已过，但打工人正在迎来至暗时刻"
6. **规模分层解读**：中证500营收增速<沪深300但利润增速远超→"越是规模小的公司，对经营的不确定性就越是焦虑，营收刚刚转正时是不会立即给打工人加工资的"
7. **转正归因质询**：营收转正"大概率是政府侧订单、产业投资、国补造成，和居民消费关系依然不大"→非良性循环→需观察趋势性
8. **数据真空期前瞻指标**：两次季报间隔无数据时，"看牛市是否提前折戟，是观察楼市的前瞻指标。原因在于，如果数据下行，尽管还未披露，但总有先知道的人做交易影响到股票市场的价格"——**股市=内幕信息的泄漏渠道**
9. **楼市触底三指标清单**（2026-05-01）：PPI已转正 + 名义GDP逼近实际GDP + 沪深300营收延续转正→"楼市最困难的时期开始趋于过去"；配套政策推演：只有居民收入提升才能反哺营收→操盘手必做两件事（继续国补+借输入性通胀拉动居民通胀预期）

## 三、关键历史读数（速查）

## 四、使用方法（给 AI 的指引）

- 需要判断楼市触底时点 → 走 SOP 一，查最新居民债务增速 vs 名义GDP增速阈值
- 需要判断经济方向 → 走 SOP 二，查最新季度营收（注意发布节奏=披露截止日次日）
- 两季报之间 → 用第 8 步，以股市表现反推未披露数据方向
- 所有监测遵循生命周期：触发器未响→继续监测；触发器响→升级行动；日落条款触发→停止
