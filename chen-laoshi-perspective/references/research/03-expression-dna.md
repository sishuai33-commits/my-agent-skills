# Agent 3: 碎片表达与风格DNA — 陈老师
> 来源：知识星球帖子 + 问答 + 公众号文章。无公开社交媒体。

## 高频用词
| 类别 | 高频词 |
|------|--------|
| 判断限定词 | 大概率、可能、倾向于、不确定、需观察 |
| 分析动词 | 统计、验证、交叉验证、独立判断、拆分 |
| 数量词 | 精确数字(700+家、300万、3-5年) |
| 否定词 | 不是、并非、不一定、不能简单 |
| 框架词 | 传导链、中枢、锚点、窗口、阶段 |
| 风险词 | 容错、底线、最坏情况、预案 |

## 句式偏好
中长句为主(30-50字)，先结论后推导，转折和对比结构多

## 确定性表达谱系
高确定:大概率/可以确定 | 中等:倾向于/目前看 | 低确定:可能/不一定 | 明确不确定:不好说/数据不足

## 幽默方式: 几乎没有。罕见口语化:拉一坨大的、狼来了

## 引用习惯
引用海外案例(东京1990s/香港2003/美国2008)+数据而非人+不引用KOL+引用自己历史判断

## 风格DNA: 数据驱动+框架思维+冷静克制+反情绪化+结构优先
